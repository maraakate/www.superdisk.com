COMMAND LINE SWITCHES DEFINITIONS

The SuperDisk Driver is designed to perform in the best possible parallel port I/O mode by detecting the host parallel port chipset make and type. By default, the driver will try to perform I/O in EPP mode. However, if the host does not support this mode, the driver will perform at a lower speed I/O mode.

The automatic speed detection routine in the driver has been refined over the past few years to work reliably on most systems. However, it may fail to work as intended on a few systems, due to non-standard implementation of parallel port hardware. On these occasions, the driver software may not detect the peripheral device attached to the parallel port. In such cases, to activate access to the peripheral device, the driver is designed with a set of command line switch options which can be applied to force a certain mode of operation.

For information on how to set command line switches, refer to Adding Command Line Switches

A list of command line switches that can be assigned to the SD120PPD.SYS drivers irrespective of the operating system used is as follows:

/rx - where x is a range from 0 to 12. With this switch, the user can force a specific READ mode. It is safe to use the default read mode. However, if it is determined that the default mode operation is causing errors, then a different mode can be used. Read modes vary from 0 to 12 as follows:

  • 0 = Nibble fast
  • 1 = Nibble normal
  • 2 = Nibble slow
  • 3 = Unidir fast
  • 4 = Unidir normal
  • 5 = Unidir slow
  • 6 = *Not used
  • 7 = *Not used
  • 8 = Bi-dir fast
  • 9 = Bi-dir normal
  • 10 = EPP normal
  • 11 = EPP fast
  • 12 = ECP 12
/wy - where y is a range from 0 to 5. With this switch, the user can force a specific WRITE mode. It is safe to use the default write mode. However, if it is determined that the default mode operation is causing errors, then a different mode can be used. In assigning these switches, the same rules apply as stated for the read modes. Since the write operation is an output function, then the architecture of any given parallel port will allow for the faster write speeds. Write modes vary from 0 to 5 as follows:
  • 0 = SSP fast
  • 1 = SSP normal
  • 2 = SSP slow
  • 3 = EPP normal
  • 4 = EPP fast
  • 5 = ECP
/de - Disables EPP Assertion

/db - Disables EPPBIOS check

/dp - Skips PS/2 DMA Arbitration disable

/ni - Skips chipset initialization

/sf - Suppresses Fast Mode detection

When the software drivers load, they follow a predetermined detection routine. On occasion, this routine fails to negotiate with the host system on a proper method of communication. If the driver that configures the external adapter and the PC fail to agree, then the driver will not have the desired effect of transmitting the signals back and forth as it was designed to do. The options listed above are designed to circumvent the usual detection routine by forcing the driver to skip certain parts of the negotiation process.

Irq =x - force irq 'x' (1 to 15)
port = 0xYYY-> force portbase yyy

On machines like the NEC 9800 series, the driver requires the parallel port base values. The 0x prefix is mandatory. YYY is the port base (e.g., 140) and Z is the IRQ value (e.g., 12).

* NEW * Parallel Port Drive: Version 1.43 supports all versions of Imation Parallel Port drives.

Version 1.43 enhancements include:

  • improved support for high speed systems. (1.43)
  • fixed bug causing memory leak in some systems. (1.43)
  • support for 2X drive version.
  • improved user interface during the install process.
  • full support for disk formatting of SuperDisks, HD and DD floppy disks in Windows95 and Windows98.
  • custom icon support for the SuperDisk™ drive.
  • local printer sharing support for NT systems.
  • support for a larger variety of parallel ports found in newer systems.


NOTE: If your present SuperDisk Parallel Port Drive is operating satisfactorily this update is not recommended. No additional performace will be obtained with this driver.

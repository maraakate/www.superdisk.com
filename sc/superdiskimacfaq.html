Question: What is USB?

Answer: The Universal Serial Bus (USB) is a new standard for low and medium speed serial devices. It allows up to 127 different devices to be connected to one USB computer system. In the next few years, it will replace the common serial port and parallel ports in most computers.



Question: What types of diskettes will my SuperDisk USB drive read?

Answer: SuperDisk - Macintosh formatted, 118.4 MB
SuperDisk - PC formatted, 120.3 MB

HD Diskette - Macintosh formatted, 1.40 MB
HD Diskette - PC formatted, 1.44 MB

DD Diskette - PC formatted, 720 KB
Note: Macintosh 800 KB is not supported. It appears as a blank diskette, or you will receive a message asking you if you want to initialize the disk to a PC 720KB formatted diskette.



Question: I've heard the Imation SuperDisk USB Drive for iMac is hot-pluggable. What does that mean?

Answer: The new USB interface on your iMac computer allows you to simply connect or disconnect your SuperDisk drive at anytime; without having to turn off your computer. This feature is called hot-plugging or hot-unplugging.

However, always close any open files and eject any diskette in the SuperDisk drive before disconnecting it from the iMac. This ensures the iMac operating system has completed all communication with the drive.



Question: I formatted a SuperDisk™ to a PC and now I can't convert it back to a Macintosh™ format. What do I do?

Answer: PC Exchange must be disabled. Eject the PC formated SuperDisk. Open PC Exchange from the control panel and click on PC Exchange - Off. Reinsert the SuperDisk and select Special\Erase\Choose format type from the list.



Question: I was copying some files to the SuperDisk™ and hot unplugged the drive. The computer froze. I thought USB could be hot unplugged?

Answer: The USB drive can only be unplugged when the drive is not active. The drive’s LED should not be on when unplugging it from the computer.



Question: I was working with a document on the SuperDisk drive. While it was in sleep mode, I disconnected the drive to use it on another computer. When I reattached the drive to the computer, it didnt work right. Whats wrong?

Answer: You can not remove the drive or eject a disk from the drive when a file is open on the disk.



Question: I inserted a SuperDisk™ into the drive, the green LED is on continuously. What’s wrong?

Answer: You may have a damaged disk. Try a different SuperDisk in the drive.



Question: I plugged in the SuperDisk™ USB drive, but I don’t see an icon on the desktop.

Answer: If no desktop icon displays after you insert a diskette in the drive, complete the following checks:

  • Make sure you have a diskette in the SuperDisk drive.
  • Make sure all cables are securely connected.
  • Make sure the computer and drive have power.
  • Make sure you are using the cables that came with the drive.
  • If it still doesn’t work, eject the disk using the button on the drive. Unplug the USB connection on the computer. Reseat the USB cable at the rear of the drive. - Plug the drive back into the power source, reconnect to computer, and reinsert the diskette.



    Question: I cannot install software that requires multiple floppy disks from my USB SuperDisk drive. What is wrong?

    Answer: Programs that require installing software from multiple floppy disks use an eject command that is dedicated to the internal or Superdrive floppy for the legacy Macintosh. That command will not work with the USB SuperDisk drive. There are two methods that allow you to install your software. One of the following two methods should work for your particular software:

    Method 1

    1. Create a temporary folder on the desktop.
    2. Insert disk 1 of the application into the SuperDisk drive.
    3. Click on the Disk 1 icon and drag it to the temporary folder.
    4. After the disk is copied, eject the disk. (You can use Command E or drag it to the trash.)
    5. Repeat the previous steps with each disk of the installation set.
    6. Double-click on the temporary folder to open it.
    7. Double-click on Disk 1 to open it.
    8. Drag the "Installer" and "Install Script" in Disk 1 to the temporary folder.
    9. Close Disk 1.
    10. Double-click on the "Install" icon to install your software. After the software has installed, you can drag the temporary folder and its contents to the trash.


    Method 2

    1. Create a temporary folder on the deskop.
    2. Insert disk 1 of the installation software into the SuperDisk drive.
    3. Double-click on the disk 1 icon to open it.
    4. Select all the files (Command A)and drag them to the temporary folder.
    5. Repeat the previous steps with each disk in the installation set. Copying all the files into the single temporary folder.
    6. After all the files are copied, double-click on "Install" or the name of the software's installer.
    7. After the software is installed, you can drag the temporary folder and its contents to the trash.


    Question: How do I install QuarkXpress on my iMac or G3 Macintosh using the SuperDisk drive?

    Answer: First, make disk images of the Install and User Registration disks using Apple's Disk Copy version 6.x or later. Then install from these. To begin the install:

    1. Make disk images of both the Installer Disk and the User Registration Disk. Be sure to create the images in read/write format, as the installer needs to write to both the installer disk and the user registration disk.
    2. Copy the disk images (files have an .img suffix) to your computer.
    3. Mount the images on your computer by double-clicking them.
    4. Insert the CD into your CD drive tray.
    5. Launch the installer.
    6. Complete the registration information. A dialog appears prompting you to insert the Installer Disk.
    7. Click Cancel. A dialog appears thanking you for using Quark's registration process.
    8. Click OK. The install proceeds normally from this point.

    To complete the install and registration process:
    1. 1.Make floppies from the disk images by launching Disk Copy (found on the Mac OS 8 CD in the Utilities folder) and then selecting Make a Floppy from the Utilities menu. You are prompted to locate a disk image file and then to insert a floppy.
    2. 2.Copy the images to blank floppies and send Quark the floppy made from the URD. The other floppy is theirs keep. Quark will use it to reinstall, since their original Install disk will prompt for the registration information.

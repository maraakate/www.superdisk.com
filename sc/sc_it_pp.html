BEFORE YOU INSTALL THE SUPERDISK DRIVERS: SYSTEM REQUIREMENTS
  1. Make sure your computer's Parallel Port is functioning properly. If you were using other devices, such as printer or scanner, out of your Parallel Port, you can be sure it is working.

  2. Make sure your computer is running DOS 6.0 or higher version, Win 3.x, Win95 or Win NT.

  3. Use the cables provided in the box. (Don't use just any cables.)

  4. Check your hardware:

    • Make sure you have power to the SuperDisk Drive by plugging it into a separate outlet and inserting a SuperDisk. The drive does a test-read of the disk and makes initialization sounds. If no sound comes from the drive, the drive might not have power to it.

    • Check the connections at the back of the SuperDisk or try a different outlet.

    • If the drive still does not work, return the drive to your retailer and get a replacement SuperDisk.

  5. Search for the following DRVWPPQT.VXD file using the following steps:

    • Once in Windows 95, click on the Start button.

    • Select Find > Files or Folders. Make sure you search all your hard drives.

    • In the Named box, type DRVWPPQT.VXD

    • Click on Find Now.

    • If you find the file, rename the file extension to .VX_ (i.e. DRVWPPQT.VX_). The file is usually located in C:\Windows\System\Iosubsys. If the file is hidden, go to View > Options > View and select Show All Files > Apply.

  6. If you are installing the SuperDisk in a Windows NT environment, make sure you have administrator rights. If you do not have Admin. rights, contact you system Administrator.

  7. If you have McAfee virus scanning Software v 3.0.2, you must upgrade this software before installing the SuperDisk. This can be done by downloading the latest update from McAfee's Web page.
INSTALLING THE SUPERDISK DRIVE
  1. Shut down your computer.

  2. Connect the Parallel Cable provided in the box. Connect it from the computer's printer port to the back of the SuperDisk. This connection is the one closest to the power jack.

  3. Plug the power pack to the SuperDisk and to an active outlet.

  4. Do not connect any other device to the pass-through port of the SuperDisk. Wait until you have a fully connected and running SuperDisk drive before you start adding other devices such as a printer or a scanner.

  5. Do not have anything connected between the computer's printer ports and the SuperDisk. If you have an A/B switch, you need to remove it while installing the SuperDisk.

  6. Power up your computer.

  7. If there is any software running in the background, make sure you disable it.

  8. Insert the appropriate installation diskette in your floppy drive.

  9. Go to Start > Run > a:\setup.exe

  10. Proceed through the installation.

  11. Once you finish the installation, restart your computer.

  12. Go to My Computer and check for a SuperDisk drive letter.
Note: For DOS users, see instructions provided in the Read me file provided with the DOS drivers.

Installing a SuperDisk Drive on a Dell Optiplex Computer.

If you have a Dell Optiplex computer, you need to load the software in Safe Mode and add the /ni switch.

Use the following procedure:

  1. Restart your computer and press F8 before Windows 95 comes up. A menu screen appears.

  2. Select Safe Mode from the menu.

  3. Once the computer has booted into Windows Safe Mode, un-install all the SuperDisk software. If you do not know how to un-install software, refer to How to Un-install the SuperDisk Software. (If loaded, the SuperDisk Accelerator software must be un-installed first.)

  4. Install the SuperDisk driver. Use the suggested default directory. As the install progresses, the message Hardware Initialization Failure appears. Select the option called I will connect the Imation SuperDisk Drive - Parallel port later.

  5. Press Finish.

  6. Add the following command line switches /w95 /ni . See Adding Command Line Switches. Note: Make sure you put spaces between each command line switch.

  7. Follow the prompts to reboot your system. (Powering off the system, resets the port.)

    Note: You should power off both your computer and the SuperDisk. This resets both units.

    Installing a SuperDisk Drive on a Parallel-PCI Printer Port.

    The SuperDisk parallel port drive uses standard ISA LPT addresses (0278h or 0378h). Parallel-PCI printer ports take LPT addresses beyond the standard range of ISA I/O addresses.

    Before installing the SuperDisk on a Parallel-PCI port, you must manually change the address of your Parallel-PCI port. (The most suitable address for the SuperDisk is 0378h.) For instructions on how to manually change your Parallel-PCI port address, please refer to your Parallel-PCI port manual.

    After changing the address of the Parallel-PCI port, complete the following steps to install the SuperDisk:

    1. Restart your computer and press F8 before Windows 95 comes up. A menu screen appears.

    2. Select Safe Mode from the menu.

    3. Install the SuperDisk driver. Use the suggested default directory. As the install progresses, the message Hardware Initialization Failure appears. Select the option called I will connect the Imation SuperDisk Drive - Parallel port later.

    4. Press Finish.

    5. Add the following command line switches IRQ=x. Change the x value to the number of the Input/Output range of your Parallel-PCI port. See Adding Command Line Switches. Note: Make sure you put spaces between each command line switch.

    6. Follow the prompts to reboot your system. (Powering off the system, resets the port.)

      Note: You should power off both your computer and the SuperDisk. This resets both units.

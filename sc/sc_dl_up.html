USB Driver for Windows™ 98

* NEW * USB Driver for the PC ;
 IMPORTANT: There are now two different USB drivers for Windows 98 depending upon the drive model. For your convienence these drivers have been combined into a single download

Version 3.0 is for model SD-USB-U3. Note the U3 drive can be distinguished from earlier versions by its use of a standard USB A-B interconnect cable.

Version 2.07b for model SD-USB-U2 or earlier Imation USB Drives. [USB cable is 36 pin at drive end, USB type A at computer end.]

Version 3.0 features include:

  • Provides support for drive model SD-USB-U3

Version 2.07b features include:

  • Fixes potential out of memory error. (2.07b)
  • self-extracting installer

See FAQs for more information.

I have an Hp Laserjet 5L family printer System connected to the SuperDisk™ and the SuperDisk™ does not work

There is currently only one printer that has caused problems on a regular basis. This printer is the HP LaserJet 5L family of printers. These printers are not meant to be used with any other device on the parallel port. However, this can be corrected.

The following solution is from the Hewlett-Packard web site. SOLUTION: To allow the zip drive, tape back up system, switch box or other device associated with the printer's parallel connection to work properly, the HP Status Window must be uninstalled or disabled. Use the following steps to uninstall:

Windows 3.1X

  1. Close all applications.

  2. From the Program Manager, locate and open the HP LaserJet 5Lgroup.

  3. Select the Uninstall icon. The following message displays:
    "You are about to remove the HP LaserJet 5L Printing System from your computer. Are you sure you want to continue?"

  4. Choose YES. Restart Windows when prompted.

  5. From the Program Manager select File>Run.

  6. Place disk #1 of the HP LaserJet 5L Printing System for Windows into the a:\ drive.

  7. In the command line type - a:\setup and press Enter.

  8. Choose the Custom installation. In the "Select Components" window choose the HP LaserJet 5L (PCL) printer driver and deselect the "Status Window" option. Continue with the installation changing disks when prompted.

  9. Restart Windows.
Note: Change the graphics mode in the PCL driver to HP-GL/2 for fastest printing.

Windows 95

  1. Close all applications.

  2. From the Windows 95 Desktop, select START>PROGRAMS and open the HP LaserJet 5L group.

  3. Select the Uninstall icon. The following message displays:
    You are about to remove the HP LaserJet 5L Printing System from your computer. Are you sure you want to proceed?"

  4. Choose YES. Restart Windows.

  5. From the Window 95 Desktop select START/RUN.

  6. Place disk #1 of the HP LaserJet 5L Printing System for Windows into the a:\ drive.

  7. In the open line type a:\setup and then, press Enter.

  8. Choose the Custom installation. In the "Select Components" window choose the HP LaserJet 5L (PCL) printer driver and deselect the "Status Window" option. Continue with the installation changing disks as needed.

  9. Restart Windows when prompted.
Note: Change the graphics mode in the PCL driver to HP-GL/2 for fastest printing. Use the following steps to disable the HP LaserJet 5L PCL Status Window:

Windows 3.1X, Windows 95

  1. Open the HP LaserJet 5L (PCL) Status Window.

  2. Select OPTIONS, then choose NO STATUS. Answer YES and OK to the messages that appear.

  3. Restart Windows.
Note: Remember to change the graphics mode in the PCL driver to HP-GL/2 for fastest printing.

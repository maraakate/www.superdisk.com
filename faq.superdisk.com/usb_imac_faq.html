Question: What is a USB Port?

Answer: The Universal Serial Bus (USB) is a new standard for low and medium speed serial devices. It allows up to 127 different devices to be connected to one USB computer system. In the next few years, the USB will replace the common serial and parallel ports in most computers.

Question: What types of diskettes will my SuperDisk USB Drive read?

Answer: The SuperDisk USB Drive will read most standard 3.5 floppy and LS-120 diskettes including:

  • SuperDisk-Macintosh™ formatted, 118.4 MB
  • SuperDisk-PC formatted, 120.3 MB
  • HD Diskette-Macintosh™ formatted, 1.4 MB
  • HD Diskette-PC formatted, 1.4 MB
  • DD Diskette-PC formatted, 720 KB
Note: Macintosh™ Formatted diskettes (800 KB) are not supported. When inserted the disk appears as a nonformatted diskette.

Question: Is the SuperDisk USB Drive for Macintosh bootable?

Answer: No. Like other USB devices, the drive is non-bootable. To get a copy of current USB specifications, visit http://www.usb.org/developers/index.html.

Question: I've heard the Imation SuperDisk USB Drive for Macintosh™ is hot-pluggable. What does that mean?

Answer: The new USB interface on your iMac computer allows you to simply connect or disconnect your SuperDisk Drive at anytime; without having to turn off your computer. This feature is called hot-plugging or hot-unplugging.

Always be sure, however, to close any open files and eject any diskettes in the SuperDisk Drive before disconnecting it from the iMac. This ensures the iMac operating system has completed all communication with the drive.

Note: The USB drive can only be unplugged when the drive is not active. The drive’s LED should not be on when unplugging it from the computer.

Question: I formatted a SuperDisk Diskette to a PC IBM compatible format and now I can't convert it back to a Macintosh™ format. What should I do?

Answer: You will need to disable the PC Exchange. Eject the PC formated SuperDisk Diskette from the drive. Then open the PC Exchange from the control panel and click on PC Exchange - Off. Reinsert the SuperDisk Diskette and select Special\Erase\Choose format type from the list.

Question: I plugged in the SuperDisk USB drive, but I don’t see an icon on the desktop.

Answer: If no desktop icon displays after you insert a diskette in the drive, complete the following checks:

  • Make sure you have a diskette in the SuperDisk Drive.

  • Make sure all cables are securely connected.

  • Make sure the computer and drive have power.

  • Make sure you are using the cables that came with the drive.

  • If it still doesn’t work:
  1. Eject the disk using the button on the drive.
  2. Unplug the USB connection on the computer
  3. Disconnect the USB cable at the rear of the drive, then reattach so that the latch is snapped securely in place.
  4. Plug the drive back into the power source, reconnect the USB Cable to the computer, and reinsert the diskette into the drive.

Question: I can not install software that requires multiple floppy disks from my USB SuperDisk™ drive. What is wrong?

Answer: A new driver is available that corrects most of the problems associated with multiple floppy installs. Click hereto get to the SuperDisk driver page. Scroll to the USB section to down load the new driver. This will correct this problem

If after installing version 1.1 of the driver you still have problems with a particular install please follow one of the methods below to complete your software installation.


Method 1 (for Apple based installers)

  1. Create a temporary folder on the desktop.
  2. Insert disk 1 of the application into the SuperDisk drive.
  3. Click on the Disk 1 icon and drag it to the temporary folder.
  4. After the disk is copied, eject the disk. (You can use Command E or drag it to the trash.)
  5. Repeat the previous steps with each disk of the installation set.
  6. Double-click on the temporary folder to open it.
  7. Double-click on Disk 1 to open it.
  8. Drag the "Installer" and "Install Script" in Disk 1 to the temporary folder.
  9. Close Disk 1.
  10. Double-click on the "Install" icon to install your software. After the software has installed, you can drag the temporary folder and its contents to the trash.



Method 2

  1. Create a temporary folder on the desktop.
  2. Insert disk 1 of the installation software into the SuperDisk drive.
  3. Double-click on the disk 1 icon to open it.
  4. Select all the files (Command A)and drag them to the temporary folder.
  5. Repeat the previous steps with each disk in the installation set. Copying all the files into the single temporary folder.
  6. After all the files are copied, double-click on "Install" or the name of the software's installer.
  7. After the software is installed, you can drag the temporary folder and its contents to the trash.


Method 3 for Quark Express 4.0

    To install QuarkXPress on an iMac using a USB SuperDrive, you need to make disk images of the Install and User Registration disks using Apple's Disk Copy, version 6.x or later, and install from these.

    To begin the install:

  1. Make disk images of both the Installer Disk and the User Registration Disk. Be sure to create the images in Read/Write format, as the installer needs to write to both the installer disk and the user registration disk.
  2. Copy the disk images (the files have a .img suffix) to the iMac.
  3. Mount the images on the iMac by double-clicking them.
  4. Insert the CD into the iMac
  5. Launch the installer.
  6. Complete the registration information.

    7. << A dialogue appears prompting you to insert the Installer Disk>>
  7. Click Cancel.

    8. << A dialogue appears thanking you for using Quark's registration process>>
  8. Click OK.

    9. << The install will proceed normally from this point.>>

    To complete the install and registration process:

  1. Make floppies from the disk images, by launching Disk Copy, and selecting Make a Floppy from the Utilities menu.

    2. << This will prompt the user to locate a disk image file, and then insert a floppy.>
  2. The user should copy the images to blank floppies, and send Quark the floppy made from the URD.
  3. The other floppy is theirs to keep, and they should use it to reinstall, since their original Install disk will prompt for the registration info.

Note: Disk Copy can be found on the Mac OS 8 CD in the Utilities folder, or at http://til.info.apple.com/swupdates.nsf/search.

Question: What is the difference between the Apple USB Mass Storage Support driver and the Imation USB SuperDisk driver?

Answer: The Apple driver was designed to be more generic and support several different drives. It does work with the Imation SuperDisk drive. There are some differences to be aware of;

1. The latest USB Mass Storage Support driver (version 1.3.5) from Apple will load in place of the SuperDisk driver when both are installed if the SuperDisk driver is less than version 2.0. If you wish to use the Imation driver you should either disable the Mass Storage Support driver, or update to version 2.0 of the Imation driver.

2. The Imation SuperDisk driver supports copy protected, or key disks,when used in conjunction with the PACE USB Floppy Enabler. The Mass Storage Support driver does not support this feature.

3. Both the MassStorage Support driver and the SuperDisk Driver version 2.0 address some issues that in some rare cases could cause the USB bus to hang in a wait forever loop.

4. Apple's Mass Storage Support requires Mac OS 8.6, while the Imation driver can use Mac OS from version 8.1 to 8.6.

5. Both drivers should have the recommended Mac OS ROM updates and iMac firmware update installed, to provide the most satisfactory operation. These vary by operating system version and by machine version.

6. Apple's Mass Storage Support Driver has not been qualified by Imation, nor do we provide technical support for any problems you may encounter when using their driver.

Question: Is installing the SuperDisk Internal IDE Drive difficult?

Answer: The installation process is direct and fairly easy. If you are installing the SuperDisk Internal IDE Drive as a bootable drive, or if you are installing the SuperDisk Internal IDE Drive into a 5.25" bay, the installation process may take longer. Checking System Configuration in the installation manual describes the CMOS setup required for installing SuperDisk as a bootable drive; Hardware Installation describes specifically how to install the SuperDisk Internal IDE Drive into a 5.25" bay.

Question: How do I know if my system is detecting the SuperDisk Drive correctly?

Answer: If your system fully supports the SuperDisk Drive and states at boot up that it has found a UHD, LS-120, or SuperDisk Drive, then it is probably fine. If it finds Floptical, note that the SuperDisk Drive is a 120MB drive and not a floptical device. If the BIOS detects the SuperDisk Drive as a hard drive or as a CD-ROM, make sure your CMOS setup is correct.If the BIOS does not make any report of the SuperDisk Drive, make certain that your jumpers are set correctly, cables are in good repair and attached correctly, and IDE port is functional. You may have to try different jumper settings to find a configuration that works (for example, if your CD-ROM was Master and the SuperDisk Drive was Slave, reverse the settings or move the SuperDisk Drive to a different IDE channel).

Question: Can I boot from the SuperDisk Drive?

Answer: Can I boot from the SuperDisk Drive? Maybe; if your BIOS supports the SuperDisk Drive, you can boot directly from the SuperDisk Drive. See Checking System Configuration in the installation manual for information on how to determine BIOS compatibility.

If your BIOS does not support the SuperDisk Drive, you can still boot from the SuperDisk drive by installing a SuperDisk Drive Adapter Board for your convenience). Currently, the adapter is available only as an ISA-type card.

Only Windows™ 95 OSR/2, 98, and NT support booting from the SuperDisk Drive directly into Windows™. You can always leave your default boot drive standard and add the SuperDisk Drive as an additional drive. Booting to Windows™ 3.x is not possible with any version of DOS.

Question: Does the SuperDisk Internal IDE Drive require a special diskette?

Answer: If you want to store more than 1.44MB on a diskette, you need Imation SuperDisk Diskettes. A regular 1.44 diskette acts as a standard 1.44MB diskette in the SuperDisk Internal IDE Drive. You can use either double density or high density diskettes.

Question: Can I use my floppy drive cleaning kit on the SuperDisk Drive?

Answer: Only if it has the LS-120 SuperDisk Drive logo on it and comes with documentation that states it can be used on SuperDisk (LS-120) Drives.

Question: Can I mount the SuperDisk Drive vertically?

Answer: Yes, but this is not recommended. The drive works best when mounted horizontally.

Question: On the Performance tab (right-click My Computer and click Properties), I see a note that drive X is running in DOS compatibility mode. What does this mean?

Answer: To run old drives, Microsoft™ provided compatibility mode. Your drive will function but not at its fastest speed. This type of compatibility issue can also occur because of hardware conflicts.

Question: What settings are important in my BIOS configuration?

Answer: Boot sequence order, SuperDisk Drive name, floppy drive and floppy drive controller status are all important Please contact your computer manufacturer or mother board manufacturer to obtain the correct BIOS update if availabe.

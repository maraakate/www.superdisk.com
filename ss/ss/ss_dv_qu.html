  1. What type of computer are you using (desktop or notebook)?
    1. If desktop, continue to 2
    2. If notebook
      1. replacement drives for swappable bays are available for some notebook computer models-check with your notebook
      2. otherwise go to Imation SuperDisk PCMCIA Drive qualifier list
      3. Otherwise go to Imation SuperDisk Parallel Port Drive qualifier list

  2. What type of operating system are you using?
    1. If Windows or DOS, continue to 3
    2. If other operating system:
      1. Mac OS - SCSI - refer to Winstation
      2. Mac OS (iMac) - USB - go to Imation Superdisk USB drive qualifier list
      3. OS/2 - drivers available on the internet (this site not supported by Imation)
      4. Unix - not aware of any drivers
      5. Linux - drivers available on the internet (not supported by Imation)
      6. Solaris (Sun) - refer to Winstation
      7. others - not aware of any drviers

  3. Do you have a bay available on the computer (either existing floppy drive bay or another one)?
    1. If yes, continue to 4
    2. If no, go to Imation SuperDisk Parallel Port Drive qualifier list

  4. What type of bay is it?
    1. If standard 3.5" bay continue to 5
    2. If standard 5.25" bay, then need to purchase standard 3.5" diskette drive mounting adaptor for 5.25" bay (included in Imation retail internal drive kit)
    3. If non-standard 3.5" bay (for example, floppy bay with curved bezel) - then may not be able to use the Imation internal drive kit without a special diskette eject button - go to Imation SuperDisk Parallel Port Drive qualifier checklist

  5. Do you have power available for that bay? (Not a likely problem if you will be replaceing the floppy drive)
    1. If yes, continue to 6
    2. If no, go to Imation SuperDisk Parallel Port Drive qualifier checklist

  6. Do you have an IDE controller enabled on your computer?
    1. If yes, continue to 7 (if you have IDE hard disk drive or IDE CD-ROM drive, then you will have IDE controller enabled)
    2. If no, go to Imation SuperDisk Parallel Port Drive qualifier checklist

  7. Do you have a vacant IDE position available, either on the motherboard or on the hard disk drive cable or the CD-ROM drive cable?
    1. If yes, continue to 8
    2. If no, go to Imation SuperDisk Parallel Port Drive qualifier checklist

  8. Can you reach the motherboard or the other available IDE connector from your open bay with the 18" IDE cable supplied with the drive kit?
    1. If yes, continue to 9
    2. If no, go to Imation SuperDisk Parallel Port Drive qualifier checklist

  9. How does your operating system support SuperDisk?
    1. Native drive support (no device drivers needed)
      1. Windows 98
      2. Windows 95 version 4.00.950b (OSR2 with built in ATAPI support)
      3. Windows NT 4.0 (check SuperDisk Website for Service Pack 3 issues)
      4. Windows NT 3.51 with Service Pack 5
    2. Drivers Needed (packaged with the internal drive kit)
      1. Windows NT 3.51
      2. Windows 95 version 4.00.950 (Microsoft's original release)
      3. Windows 95 version 4.00.950a (Microsoft's original release with Service Pack 1)
      4. Windows 3.1 or 3.11
      5. DOS 5.0 or higher

  10. Note: If you need to install the drivers from the diskettes provided, you will need to keep your standard floppy drive attached until after the drivers are installed

  11. Do you want the SuperDisk drive installed as your boot drive?
    1. If yes, continue to 12
    2. If no, you may install the SuperDisk drive in any open bay, following the enclosed instructions

  12. Note: You need to find out whether your motherboard supports SuperDisk as a bootable drive, by:
    1. Asking your motherboard supplier, or
    2. Installing and testing the SuperDisk drive with your motherboard (if your BIOS does not recognize the SuperDisk drive, you may need to change the BIOS settings that relate to SuperDisk/LS-120)

  13. Does your motherboard BIOS support SuperDisk drives as bootable drives?
    1. If yes, continue to 14
    2. If no,
      1. upgrade your BIOS (not recommended for casual users)
      2. contact motherboard manufacturer for a new motherboard (for a VAR who wants to configure computers)
      3. OR install internal SuperDisk drive as non-bootable drive
      4. OR go to Imation SuperDisk Parallel Port Drive qualifier checklist
    3. If you don't know,
      1. install and test the SuperDisk drive in your computer (if your BIOS does not recognize the SuperDisk drive, you may need to change the BIOS settings that relate to SuperDisk/LS-120

  14. CONGRATULATIONS! You should be able to install the SuperDisk drive as your bootable a: drive. See you drive's user's manual for details
